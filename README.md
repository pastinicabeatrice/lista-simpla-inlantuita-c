# Agenții bancare - listă de liste

Listă simplu înlănțuită de agenții, citite din fișier, și gruparea lor într-o listă de liste.

## Funcționalități

- citirea agențiilor din `agentii.txt`
- ștergerea agențiilor cu cod impar
- gruparea agențiilor după numărul de clienți (listă de liste)
- scrierea rezultatelor în fișiere și dezalocarea memoriei

## Structura de date

`Agentie`: cod, denumire, profit, adresă, număr de clienți.

## Rulare

Se deschide `listaSimplaInlantuita.sln` în Visual Studio. Fișierul `agentii.txt` trebuie să fie în directorul de lucru.
